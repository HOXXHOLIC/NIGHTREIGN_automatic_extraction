## 工具介绍
黑环自动刷遗物工具通过不断SL来刷取游戏艾尔登法环黑夜君临中的目标遗物  
该工具原为我群内自用，现加上UI后，分享至游戏社区，未来大概率不会更新
## 系统要求
windows版本: win10 or win11  
.NET版本: .NET Framework 4.7.2  

请确保你的计算机上安装了.NET Framework 4.7.2  
[.NET Framework 4.7.2下载官网](https://dotnet.microsoft.com/zh-cn/download/dotnet-framework/thank-you/net472-fra)

如果你是混合DPI多屏，那脚本可能运行不正常（~~我懒所所以没做适配~~）  
目前设计了DPI适配与多屏适配，游戏画面一定要设置为**无边框窗口化**

## 使用步骤
### 0.最重要的事
无论何时，在你使用脚本前，极其建议你**手动备份存档**，避免存档意外损坏  
启动脚本前，关闭**杀毒软件和windowsdefender**，或者将包含工具的文件夹添加到**排除项**（白名单）  
搭配[B站的视频](https://space.bilibili.com/573664045?spm_id_from=333.1007.0.0)使用更佳，有更清晰的教程
### 1.解压
将automatic_extraction.rar解压到一个**不含中文**的文件目录中  
**不含中文**，这很重要，因为文件目录中如果含有中文会导致paddleocr出现错误，脚本无法正常识别
### 2.启动游戏，将角色设置为追踪者
**开启游戏**，将角色设置为**追踪者**，画面设置为**无边框窗口化**。**关闭游戏**  
由于脚本是固定按键，在筛选遗物时不是追踪者会导致按键误差  
### 3.设置游戏路径与游戏存档路径
以管理员身份打开automatic_extraction_UI.exe  
在工具右下角，你能直接粘贴路径或选择路径
### 4.设置你的配置
在automatic_extraction_UI.exe中，提供了三个可选遗物槽，通过勾选来决定它是否启用  
只设置三个上限的原因是，遗物槽多了，筛选遗物的效率会降低（~~我懒~~）  
自己设置配置，但第一次启动时我建议将**抽取次数设为3**，来测试该脚本是否能正常运行  
设置完配置后一定要点击**保存配置**
### 5.点击一键启动
点击一键启动后稍等一会，游戏和脚本将会自己启动，届时会有悬浮窗显示日志  
## 常见问题
### 1.automatic_extraction_UI.exe无法打开
如果没有安装.NET Framework 4.7.2，会导致它无法打开，上面有安装下载链接，你也可以自行搜索下载  
你没有关闭杀毒软件和windowsdefender，automatic_extraction_UI.exe被干掉了
### 2.点击一键开始或更改范围后没有反应
这一般是main.exe或fix_tool.exe被杀毒软件或windowsdefender干掉了  
确保main.exe或fix_tool.exe这两个程序与automatic_extraction_UI.exe在同一文件夹中
### 3.点击一键开始后，悬浮窗出现enter_rtable 超时或in_rtable 超时
如果你的物理屏幕分辨率不是1920*1080，那大概率会出现这两种超时  
当你看见这两种超时中的一种时，说明已经等待了10分钟却仍旧无法识别到正确内容  
启动更改范围，来框选范围，这一步不好在文档内说明，建议观看[B站的视频](https://space.bilibili.com/573664045?spm_id_from=333.1007.0.0)
## 可控文件详细说明
### 关于log文件夹
automatic_extraction文件夹内会有log文件夹，当你发生了自己无法解决的错误时。  
可以将log文件夹内的所有内容在B站私信发送给我
### 关于save文件夹
automatic_extraction文件夹内会有save文件夹  
original_save文件夹内存档是我帮你备份的，这个存档的版本是你启动脚本之前的存档版本，可以使用这个版本回档  
target_save文件夹内存档是程序用的回档存档，出货了的话，存档将会保存在这个文件夹里  
blacklist_save是包含黑名单词条的存档，这也许有些多余。但由于ocr误差的原因我决定保留它，这里面的存档都是同时包含目标遗物和黑名单词条的存档  
**在每次启动main.exe**（也就是你点一键启动后），会将上面这三个文件夹清空
### 关于config.yaml
这里面有程序main.exe的通用设置  
包含mss截图的范围，也就是程序识别的范围，有  
识别遗物的区域(relic)  
识别暗痕的区域(dmark)  
识别请按任一按钮的区域(start)  

按键延时设置key_delay系列  
上面这两大类你可以根据自己的电脑进行更改，ocr_proins与mode_map我则不建议你进行自行更改
